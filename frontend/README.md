# Фронтенд интернет-магазина

Vue 3 SPA на TypeScript для FastAPI ecommerce-бэкенда.

## Быстрый старт

```bash
npm install
npm run dev
```

Фронтенд запускается на `http://localhost:5173`. Бэкенд должен быть запущен на `http://localhost:8000`.

## Стек

| Технология | Назначение |
|---|---|
| Vue 3 (Composition API, `<script setup>`) | UI-фреймворк |
| TypeScript (strict) | Типизация |
| Vite | Сборка и dev-сервер |
| Vue Router | Маршрутизация (ленивая загрузка) |
| Pinia | Управление состоянием |
| Axios | HTTP-клиент |
| Tailwind CSS | Стилизация |

## Скрипты

| Команда | Описание |
|---|---|
| `npm run dev` | Dev-сервер с горячей перезагрузкой |
| `npm run build` | Production-сборка (TypeScript-проверка + Vite) |
| `npm run preview` | Локальный предпросмотр собранного приложения |

## Прокси API

Vite dev-сервер настроен на проксирование запросов с `/api` на бэкенд:

```
/api/products  →  http://localhost:8000/products
/api/categories →  http://localhost:8000/categories
```

Rewrite убирает префикс `/api` из пути. Настройка в `vite.config.ts`.

## Архитектура

```
src/
├── types/          # TypeScript-интерфейсы (соответствуют Pydantic-схемам)
├── api/            # HTTP-сервисы (чистые обёртки над axios)
│   └── client.ts   # Экземпляр axios с JWT-перехватчиками
├── stores/         # Pinia-сторы (реактивное состояние)
├── router/         # Маршруты и навигационные guards
├── composables/    # Переиспользуемая логика (usePagination, useDebounce)
├── components/
│   ├── ui/         # Базовые компоненты (кнопка, инпут, модалка, пагинация…)
│   ├── layout/     # Шапка, подвал, обёртка
│   ├── product/    # Карточка товара, сетка, форма
│   ├── category/   # Карточка категории, дерево
│   ├── review/     # Карточка отзыва, форма, список
│   └── auth/       # Формы входа и регистрации
└── views/          # Страницы (11 маршрутов)
```

Слои зависят сверху вниз: Views → Components → Composables → Stores → API Services → Types.

## Аутентификация

- Токены хранятся в `localStorage` (access + refresh)
- Access-токен подставляется в заголовок `Authorization: Bearer ...` через axios-перехватчик
- При 401 — автоматическое обновление токена с очередью запросов (чтобы избежать лавины)
- JWT декодируется на клиенте без проверки подписи (реальная проверка — на бэкенде)

## Роли

| Роль | Возможности |
|---|---|
| **buyer** | Просмотр каталога, оставление отзывов |
| **seller** | Дашборд со своими товарами, создание/редактирование/удаление товаров |
| **admin** | Всё выше + удаление любых отзывов |

## Маршруты

| Путь | Страница | Доступ |
|---|---|---|
| `/` | Главная | Все |
| `/products` | Каталог товаров | Все |
| `/products/:id` | Карточка товара | Все |
| `/categories` | Список категорий | Все |
| `/categories/:id` | Товары категории | Все |
| `/login` | Вход | Только гости |
| `/register` | Регистрация | Только гости |
| `/seller` | Дашборд продавца | Только seller |
| `/seller/products/new` | Создание товара | Только seller |
| `/seller/products/:id/edit` | Редактирование товара | Только seller |
| `/:pathMatch(.*)*` | 404 | Все |

## Переменные окружения

Файл `.env` в корне `frontend/`:

```env
VITE_API_BASE_URL=/api
```
